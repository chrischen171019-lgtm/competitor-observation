排名与样本口径

当前仅对已采集的近 30 天应用商店评论进行人工主题归类。按来源与记录 ID 去重，同一记录在一个主题中只计一次；同一记录可同时表达正面体验与问题，所以各类次数不能相加作为用户总数。

按主题提及次数降序，相同次数标记并列；并列主题按最近提及时间展示，最多呈现五类，不足不补。横条以当前样本最多提及的主题为参照，不是满意度或用户占比。

未归类包括笼统好坏、无关内容与信息不足的评论。记录数不是独立人数，采集渠道与时间不完整；不能将这里的结果称为大多数用户的共识。没有相关样本的产品不使用外部印象补造 Top 5。

GitHub issue 为技术报告，未计入感知排名；历史主题证据仍保存在原始采集数据中。
