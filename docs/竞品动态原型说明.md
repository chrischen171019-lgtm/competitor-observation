# 竞品动态 UI 原型 v1

入口：outputs/competitor-ui-prototype.html。原站 outputs/competitor-research-complete.html 保留不变。

基于 AIHOT 开源提交 aa8e5b1bc4895267f98abe59c87dfed8a22bf35f，复用 app.css 的色彩体系，并将 Sidebar、AllPage、DayList、TimelineSlot、FeedItem 的布局适配为无构建依赖的 HTML / JavaScript 原型。许可证与署名保存在 outputs/aihot-prototype-notice.html。这不是完整 React / PostgreSQL / worker 部署。

动态内容边界：九个产品的官方公告、官方账号文章、可信媒体的产品相关报道。按原始发布时间倒序、北京时间分日，采集时间仅在证据详情中展示。评论、GitHub issue 和泛行业无关稿件不混入新闻流。GitHub 正式 Release 属于官方版本发布。媒体标题保留其归属，不改写为已验证事实。

原型使用已有采集记录中的 10 条样本；其中官方发布直接来自 WeKnora GitHub，媒体样本仍是 RSS 标题级证据。OpenAI 署名线索独立标识，未当作已核验的官方文章。官方账号当前没有接入，筛选后明确为空。后续正式接入需配置官方账号与媒体来源白名单、抓取新闻正文后提取摘要和原文地址，不根据标题补写新闻。

原型提供产品、来源、关键词和日期筛选，新闻证据弹窗，原有九产品的二级切换、章节导航与截图放大。沿用原研究章节全部正文，未新增竞品结论。

复现：python3 work/ui-prototype/build.py
交互逻辑验证：使用 Node 运行 work/ui-prototype/check.cjs。已验证筛选、空态、详情和栏目切换；研究内容与原图逐项比较，JavaScript 语法检查通过。浏览器访问被 Work 设置关闭，未进行实际浏览器的视觉和移动端验收。

本轮只确认前端原型；未改变监控定时任务、采集源或发布状态。

## v2：竞品热点榜

入口为同一 HTML 的 #section-hot，参考 AIHOT routes/hot.tsx 的前三卡片和后续榜单。九产品合并 Top 10，可筛选单产品。以采集快照截止时间向前 48 小时为窗口，按发布时间过滤，渠道去重并按 24 小时半衰期计权。当前仅为人工归组样本中的来源关注热度；没有完整账号、转载身份和互动增量，不称为全网讨论量。HN 累计评论不计热度；不展示虚构走势。算法和分组在 work/ui-prototype/hot.py，数据输出 outputs/prototype-hot.json。未改变正式采集和自动任务。

## v3：用户反馈与战略机会地图
新增独立用户反馈栏目，按产品、时间、类型和来源筛选真实记录支持的主题。移除战略页反馈、产品轨迹和下一步计划；机会地图展开为五个带任务链、证据、反证条件与 Innobook 核对项的假设。未做 Innobook 功能差距结论。旧战略正文保存在 work/ui-prototype/strategy-before-feedback.html。九产品原文与截图不变。定价和护城河历史草稿未重新核验，明确不作为本次机会判断依据。

## v4：用户感知 Top 5
用户反馈默认展示 WorkBuddy 的样本感知榜，可切换产品或跨产品主题汇总。人工审阅采集快照近 30 天应用商店评论，按具体感知多标签归类，同主题记录去重计数，最多显示五类；同数标记并列。原话、未归类记录及方法均可展开。Gemini 无可用应用商店反馈时不凑排名；新闻、技术 issue 不混入用户感知。主题编码在 work/ui-prototype/perceptions.py，保留旧主题文件用于追溯。未新增采集、未自动调用情感分析 API。
