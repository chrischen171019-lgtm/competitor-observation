# 竞品观察页面布局调整设计

## 目标

让竞品观察页面按可用屏幕宽度展开，日报和口碑观察在宽屏与移动端保持清晰、稳定的阅读对齐，并让日报往期侧栏与参考图一致。

## 设计

- 全局内容容器取消固定最大宽度，保留响应式内边距；正文、导航、筛选器和表格允许占满主区域。
- 日报正文使用统一的内容网格。双栏故事共享列起始线和列间分隔线；单个故事占满整行并从左侧阅读线开始。日报头部、正文和前后期导航使用同一左边缘。
- 日报侧栏只展示日报/周报/月报切换、年月分组、日期和标题，不展示编辑状态、采集汇总、期次状态等内部字段。移动端用期次选择器保留相同信息。
- 口碑观察卡片使用固定的排名列、内容列和右侧计数列；标题、语气标签、提及数、进度条、描述和引用有稳定的垂直节奏。长文本换行但不撑破页面；移动端降为内容单列。
- 数据层继续保留状态与采集截止时间，页面只调整展示字段。
