# 本机竞品动态推送

目标：Harness 可将竞品动态通过认证 HTTP 接口写入，网页下次读取即显示，重启或重新采集后仍然保留。

方案：沿用现有观察模块和快照读取层；新建 `POST /api/observation/events`，使用现有 `INGEST_TOKEN` 验证，接收最多 50 条带产品、来源、标题、原文链接和可选发布日期的记录。用本机 SQLite 保存外部记录，读取时与采集快照合并；不改变报告正文，不把外部提交自动当作官方已验证事实。提供独立本机启动命令，不需要 PostgreSQL。

实现顺序：

- [x] 在现有观察测试中复现认证写入、读取、重试去重、重启保留、采集快照替换保留、非法请求不写入。
- [x] 实现存储、输入校验、接收接口和合并读取，挂载可写数据目录。
- [x] 添加独立启动命令与 Harness 请求示例，生成本机密钥配置。
- [x] 运行接口与前端检查、类型检查，在隔离数据下完成真实 HTTP 推送和页面验证，清理演示数据。

验收：未授权写入返回 401；有效推送返回计数；刷新读取能查到唯一新记录；重复推送不会重复；重启及采集文件替换不丢失推送；原有报告和研究内容保留。

2026-11-10 验证：236 项 standalone 测试、17 项 Python 测试、TypeScript 类型检查、页面交互与响应式结构检查通过。真实本机 HTTP 验收覆盖认证、重试去重、非法批次拒绝、快照读取和页面脚本渲染；临时记录已清除，原始快照未修改，密钥与数据库不公开。浏览器控制未启用，因此没有宣称浏览器视觉验收或 Harness 插件本身已配置完成。
