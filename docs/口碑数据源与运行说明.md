# 竞品动态与口碑监控：第一版

更新：2026-10-26，Asia/Shanghai。

## 已实现与边界

- 每日公共来源采集、SQLite 持久化、来源内去重、原始响应留档、首次基线和历史补录标记。
- 生成 Markdown 与 HTML 日报；周报、月报为当前周期的采集汇总，尚不是 AI 趋势分析。
- 更新现有报告的动态、报告归档、新产品观察栏目；产品档案正文和截图不改。
- 没有 AI API，无 AI 摘要、情感分类或自动事实核验。原文摘录不能替代阅读原始讨论。
- 默认只取接口最近有限条目。新闻跨媒体重复、内容相似度合并、完整评论历史和多来源事件归并尚未实现。
- 当前 raw 保存完整接口响应供复核，可能含公开用户名；网页不展示用户名。请不要把 raw 数据目录直接部署。

## 目前配置的来源

- 9 个产品新闻检索 RSS：只作更新/客户线索，不视为已确认变化或用户评价。
- 3 个 Apple 中国区最新评论入口：ima 6737188438、WorkBuddy 6761374913、豆包 6459478672。身份通过 Apple 搜索的应用名与开发主体核对。
- Tencent/WeKnora 官方 GitHub Releases 与 Issues。
- NotebookLM、ChatGPT 的 Hacker News 帖子标题匹配；不是整个讨论的所有评论。
- AI 知识库/智能体发布新闻候选：只供新产品观察，不自动纳入竞品库。

RSS 或 API 可能无数据、限流或连接失败。成功响应且零样本是单独的覆盖结果。第一次跑到的旧内容不算当日发布。

## 每条口碑需要保留的数据

必要：产品与模块、原文/摘录、来源链接、评论日期、首次采集时间、平台、地区、适用版本、采集状态。

有则保留：原始评分、互动数、原帖修订、问题是否解决。原始评分只用于追溯，不做综合排名。

后续经 AI 或人工分析再补：用户身份自述、想完成的任务、好评点/痛点、复现条件、是否亲历、推广嫌疑、与其他反馈的重复关系。当前程序没有自动生成这些判断。

不要只收差评，也不要以几条吐槽概括全部用户。不同平台的评分和用户群不可直接相加。付费计划、设备、语言和地区不同需要分别理解。

## 登录或授权来源

Reddit、X、Google Play、知乎、小红书、B站、安卓市场与 G2 的自动访问方式需要逐站确认条款、接口与账号权限。当前没有自动抓取这些网站，不绕过登录或反爬。可以用授权导出或人工 JSONL 导入。

将人工核验的条目逐行写到 monitor/manual.jsonl，例如：

    {"product":"ima","category":"feedback","title":"实际帖子标题","excerpt":"保留语境的原文摘录","url":"https://来源网站/真实帖子","published_at":"2026-10-26T10:00:00+08:00"}

产品 ID：notebook、ima、lexiang、weknora、chatgpt、workbuddy、doubao、patsnap、xinghe。不得将示例当作真实反馈导入。

## 本地运行

在项目目录运行：

    python3 monitor/collect.py

运行使用 macOS /usr/bin/curl 与系统信任证书，不关闭 TLS 验证。单来源限时，最多重试一次；一个来源失败不会阻断其他来源。重复运行会更新源状态，不重复插入同一来源同一条目。

输出：

- outputs/competitor-research-complete.html：原报告＋监控栏目，可离线打开。
- outputs/monitor-data.json：事件、检查状态、历次运行及报告列表。
- data/monitor.sqlite3：去重状态和历史；不要随意删除，否则会重建基线。
- data/raw：原始证据响应；data/latest-run.json：最近执行状态。
- reports：日报、当前周/月汇总的 HTML 与 Markdown；revisions：每次生成的 HTML 留档。当前周/月仍会更新，未自动结刊。

## 本地只读 API

    python3 monitor/serve.py --port 8765

打开 http://127.0.0.1:8765 。只监听本机，不是部门网站，不对局域网开放。

- GET /api/status：最近采集与来源状态。
- GET /api/events?product=ima&category=review：按产品/类型读取记录。
- GET /api/reports：报告索引。

只提供读取，不通过网页触发采集或执行命令。网页通过 HTTP 打开时每分钟检查数据版本，发现更新后提示刷新；file:// 模式继续使用离线内容。
